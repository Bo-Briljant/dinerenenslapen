Code uit je app

Open je authenticator-app (bijvoorbeeld Google Authenticator of Microsoft Authenticator) en vul de zes cijfers in bij Dineren & Slapen.

Extra beveiliging instellen

Eenmalig: koppel een authenticator-app aan je account. Daarna log je steeds in met je wachtwoord en een code uit die app.

  1. Installeer op je telefoon Google Authenticator of Microsoft Authenticator.
  2. Kies in de app voor een nieuwe code en scan deze QR-code.
  3. Vul de zes cijfers in die de app nu laat zien.
